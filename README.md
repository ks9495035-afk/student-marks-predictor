# Student Marks Predictor

## About the Project
Student Marks Predictor is a Python-based machine learning project that predicts students' marks based on their study hours, attendance percentage, and previous marks.

## Features
- Predicts student marks.
- Accepts study hours as input.
- Accepts attendance percentage.
- Uses previous marks for prediction.
- Simple and user-friendly web interface.

## Technologies Used
- Python
- Flask
- Pandas
- Scikit-learn
- HTML
- CSS

## Machine Learning Algorithm
Linear Regression

## Project Structure
- app.py
- marks_predictor.py
- templates/index.html
## Live Demo

Try the project here: https://student-marks-predictor-18kd.onrender.com
## How to Run

1. Install Python.
2. Install the required libraries:
   `pip install flask pandas scikit-learn`
3. Run the application:
   `python app.py`
4. Open your browser and visit:
   `http://127.0.0.1:5000`

## Purpose
This project demonstrates how machine learning can be used to estimate student academic performance using basic student-related data.
